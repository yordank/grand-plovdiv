# Гранд Пловдив — месечни сметки за общите части

## Стартиране (v0.1 — прототип)

Изисква Node.js 18 или по-нов.

```bash
git clone https://github.com/yordank/grand-plovdiv.git
cd grand-plovdiv
npm install
npm test        # проверка на изчисленията
npm start       # http://localhost:3000
```

Друг порт: `PORT=8080 npm start`.

За постоянна работа на сървър (Linux):

```bash
npm install -g pm2
pm2 start server.js --name grand
pm2 save && pm2 startup
```

Файлове:
- `server.js` — Express сървър (страницата + `/api/objects`, `/api/calculate`, `/health`)
- `lib/calc.js` — изчислението по методиката
- `data/objects.json` — 257 обекта с идеални части и отметки за участие
- `public/` — интерфейсът
- `spravka/Grand_razpredelenie.xlsx` — същото изчисление в Excel
- `TASKS.md` — списък със задачите

Програма за ТАЦ „Гранд“ (гр. Пловдив, ул. „Капитан Райчо“ № 56), която всеки месец разпределя разходите за управление и поддръжка на общите части между самостоятелните обекти.

Основа: **Методика за разпределение на месечните разходи** (Приложение № 8 към Протокол от ОС на ЕС — ТАЦ „Гранд“ от 06.10.2026 г.). Методиката важи от **01.01.2027 г.** (отчетен период януари 2027). До 31.12.2026 г. се прилага досегашният ред.

## Правила за разпределение

Всеки месец управителят въвежда общата сума по всяко перо. Програмата смята дела на всеки обект.

| Перо | Как се дели | Кой НЕ участва |
|---|---|---|
| 1. Постоянни текущи разходи (охрана, чистене, асансьори, заплати, счетоводство и др.) | **поравно** между всички обекти | тераси |
| 2. Вода (ВиК) за общите части | **поравно** | гаражи, хипермаркет, тераси |
| 3. Ток за общите части (осветление, контакти, асансьори, ескалатори) | **по идеални части**, преизчислени до 100% без терасите | тераси |
| 4. Ток за ОВК системата (чилъри) | **по идеални части**, отделна база само за обслужваните обекти от 1-ви, 2-ри и 3-ти етаж | гаражи, хипермаркет, целият 4-ти етаж, тераси |

**Сметка на обект = дял 1 + дял 2 (ако участва) + дял 3 + дял 4 (ако участва).**

Формула за пропорционалните пера:

```
дял на обекта = сума на перото × (идеална част на обекта / сбор на идеалните части на участващите обекти)
```

### Приходи от общите части (чл. 10)

Приходите (реклама, LED екран, санитарни помещения, автомати и др.) се **приспадат от разходите** за месеца преди разделянето. Не се приспадат (или само частично), когато:

1. Общото събрание е решило те да отидат във фонд „Ремонт и обновяване“ или за друг проект.
2. Има просрочени задължения на собственици и парите не стигат за текущите разходи.
3. Има просрочени задължения към доставчици (ток, вода, охрана и др.), до размера на тези задължения.

### Извън методиката (чл. 3)

- лична консумация на ток (разликата между общата фактура и отчетените компоненти отива към личния ток);
- фонд „Ремонт и обновяване“;
- лична консумация на вода.

### Отчет (чл. 11)

Към всяка месечна сметка управителят показва:

1. общата сума на всеки вид разход;
2. списък на приходите и как са третирани по чл. 10.

Всички суми са в **евро (€)**.

## Препоръка: уеб приложение

**Етап 1 — панел за управителя**
- списък на обектите с идеални части и с отметки за участие (фасада, хипермаркет, гараж, чилъри, тераса);
- месечно въвеждане на разходите по 4-те пера и на приходите;
- изчисление и проверка, че сборът от сметките е равен на разпределената сума;
- PDF сметка за всеки обект и обща месечна справка по чл. 11;
- история по месеци.

**Етап 2 — портал за собствениците**
- вход за всеки собственик;
- преглед и сваляне на собствените сметки по месеци.

**Технология:** Node.js, база данни, генериране на PDF.

## Отворени въпроси към управителя

1. Кои обекти са на **фасада**? В Excel файла няма такава колона (чл. 6).
2. Кой обект е **хипермаркетът**? Вероятно „ЛЕКСИ“ (19,628%).
3. Кои обекти са **свързани към чилърите**? Всички на етажи 1–3 или само някои (чл. 8)?
4. Обектите с **0%** (1-70 и 1-71): участват ли в поравното разделяне?
5. **Разделените обекти** (напр. 2-23-1 и 2-23-2, 3-21-1 и 3-21-2): един обект или два при поравното разделяне?
6. Обектите „Дискотека-КА1“, „Кафе -2.25“, „ПИБ“, „Фреш бар“: на кой етаж са и в кои пера участват?
7. „Обща тераса“ (8,261%) третира ли се като тераса (изключена)?
8. Трябва ли програмата да **следи плащанията и дълговете**? От това зависи чл. 10, ал. 2.
9. Пример за **сегашна месечна бележка**, за да се запази форматът.
10. Кой ще използва програмата и трябва ли тя да **праща сметките по имейл**?
